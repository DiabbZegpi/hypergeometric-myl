# 📊 Serverless Hypergeometric Calculator

A modern, clean, and minimalistic dashboard built entirely in R and Shiny to compute hypergeometric probabilities. 

🚀 **[Click Here to Launch the Live Web App](https://diabbzegpi.github.io/hypergeometric-myl/)**

### 🧠 Core Features:
* **True Serverless Architecture:** Powered by Shinylive. Runs entirely inside your web browser for instant scalability and 100% free hosting via GitHub Pages.
* **Dashboard Design:** Business-intelligence style KPI metric blocks displaying Exact, Lower-tail, and Upper-tail outcomes.
* **3-Color Visual Sync:** An interactive distribution bar plot that automatically updates and color-matches its corresponding dashboard metrics.
* **Enterprise Control:** Isolated execution via an deliberate "Run Calculation" action loop to avoid premature refreshing while typing numbers.
* **Full Safety Locks:** Injected frontend scripts that physically prevent users from entering invalid decimal keys, minus signs, or letters.
